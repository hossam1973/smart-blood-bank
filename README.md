# 🩸 بنك الدم الذكي — Smart Blood Bank

تطبيق Android وiOS وويب، مع وكيل ذكاء اصطناعي، يربط **المتبرعين** و**المستفيدين** و**المستشفيات ومراكز الدم** حسب الموقع، ولكل فئة بوابة خاصة.

- المراجعة التقنية، والنماذج المشابهة، ونموذج الإيرادات: [`docs/STRATEGY.md`](docs/STRATEGY.md)

## محرك التنبؤ بالنقص
- **الأيام حتى النفاد** = الرصيد ÷ (الصرف الفعلي − الإيداع الفعلي)، لكل فصيلة، مع تاريخ تقويمي.
- **مستويات الخطر:** 🚨 حاد (أقل من 4 أيام، مع وميض)، و⚠️ إنذار (4–8 أيام أو تحت الحد الآمن)، و🟢 مستقر.
- **المواسم:** رمضان (إيداع −38%)، والحج والعمرة (صرف +20% وأكثر للفصائل السالبة)، والصيف (−30%)، والإنفلونزا (−20%)، والأعياد (صرف +25% وإيداع −25%).
- **ضغط المستشفى:** معتدل، أو مرتفع (+25%)، أو كود أحمر (+60%). **الأفق:** شريط من 7 إلى 30 يومًا.
- المعدلات تُحسب من حركات آخر 14 يومًا، وكل زر صرف أو إيداع يسجّل حركة (FEFO).
- خطة التدخل يولّدها Claude (Structured Output). إذا تأخر أو فشل، تُعرض خطة القواعد الثابتة فورًا، فلا ينقطع النظام.
- العربية والإنجليزية تلقائيًا حسب لغة الجهاز، مع زر تبديل.

## البيئة المنشورة
- مشروع Supabase: `smart-blood-bank` (فرانكفورت eu-central-1) — `https://pgcgtzlvjabrlvjfdpbh.supabase.co`
- الترحيلات 001–003 مطبّقة، والدوال `blood-agent` و`predict-shortages` و`donor-recall` منشورة.
- المتبقي: إضافة `ANTHROPIC_API_KEY` من لوحة Supabase ← Edge Functions ← Secrets. بدونه يعمل التنبؤ بالخطة الاحتياطية ويعتذر المساعد الذكي.
- `mobile/.env` غير مرفوع (في .gitignore): ضع فيه رابط المشروع والمفتاح العام `sb_publishable_...` من لوحة Supabase.

## خرائط جوجل
- أندرويد: Google Maps عبر react-native-maps. iOS: خرائط آبل افتراضيًا، أو Google بإضافة المفتاح.
- أنشئ مفتاحًا في Google Cloud Console وفعّل "Maps SDK for Android" و"Maps SDK for iOS"، ثم ضعه في `GOOGLE_MAPS_API_KEY` عند البناء (يقرؤه `app.config.ts`).
- أزرار "الاتجاهات" تفتح خرائط جوجل مباشرة ولا تحتاج مفتاحًا.
- الخصوصية: لا يظهر موقع أي متبرع. المنشأة ترى مناطق مجمّعة (~1.1 كم) فيها 3 متبرعين على الأقل.

## التشغيل
```bash
# 1) قاعدة البيانات
supabase link --project-ref <ref>
supabase db push
supabase secrets set ANTHROPIC_API_KEY=...
supabase functions deploy blood-agent
supabase functions deploy predict-shortages
supabase functions deploy donor-recall

# 2) التطبيق
cd mobile && cp .env.example .env   # ضع رابط Supabase والمفتاح العام
npm install
npx expo start            # Expo Go للتجربة
eas build -p android      # / -p ios للنشر على المتاجر
```

## ما تم التحقق منه
- ✅ `tsc --noEmit` ينجح لجميع ملفات التطبيق، والتصدير للويب ينجح (755 وحدة).
- ✅ اختبار المحرك رقميًا: O- برصيد 12 وصافي −3/يوم = 4 أيام (إنذار)، وفي رمضان 3.9 أيام (حاد).
- ✅ الترحيلات مطبقة على Supabase حقيقي، واختُبرت داخل معاملة تم التراجع عنها: حركات الصرف والإيداع، ومعدلات التنبؤ، ومنع المستخدم من ترقية نفسه إلى مدير.
- ⏳ لم تُختبر دوال الخادم بطلب حقيقي من التطبيق بعد (تحتاج مستخدمًا مسجلًا ومفتاح الذكاء الاصطناعي).
